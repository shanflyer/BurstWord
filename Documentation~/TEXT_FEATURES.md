# 文字压力测试

打开 `TextFeatures.unity` 后 Play。八种负载包括混合、数字、中日韩、复杂文字、富文本、描边/阴影/发光、彩色 Emoji 和自动换行。切换类型会清空文字并重新预热统计，所有类型均在战场受击点持续大量发射。

面板可输入每秒发射量和瞬发数量，也支持快捷档、倍增/减半、暂停、瞬发、容量扩展与清空。基础数据包括 FPS、帧耗时、采样帧数、Unity/托管内存、GC 分配与回收次数、文字/字形数量、BRG 命令、发射/丢弃以及缺字/排版失败。

排序和空间模式都可切换；目标移动/旋转/缩放用于检查跟随。GPU 动画按钮切换线性动画和四个动画预设。F1 隐藏/恢复面板。

默认只使用 TMP_FontAsset 字形数据，不强制外部塑形库。双向和断行规则由内置 Unicode 算法处理；需要额外塑形时，通过 SetTextShaper 注册标准输入、输出的委托，自写实现或调用任何插件均由使用者决定。不注册或传入 null 就跳过塑形，没有 Inspector 塑形 Asset。高级原生 Job 适配器可使用 SetTextShaperProvider。接口约定见 SHAPING.md。面板显示当前排版提供者。字体仍需要覆盖目标字形。

支持富文本、多个字体及其自带材质效果、装饰线、上下标、Sprite/Emoji、双向文本、复杂字形、连字与字距、按词/字形簇换行。正常渲染与缓存/Job 优化保留；历史验证入口、逐帧记录和详细文件导出已删除。

效果测试通过 `fontIndex: 7` / `8` 选择自带描边阴影 / 发光材质的示例字体资源，字体共享原始图集。默认示例字体的 TMP fallback 链包含其他语言字体。
