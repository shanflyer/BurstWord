# GPU 飘字动画

## 直接使用

Unity 菜单 **Tools → BurstWord → Animation Editor** 打开独立动画编辑器，不需要进入 Play，也不需要 Scene、Prefab 或编辑物体。

1. 选择 Float、Critical、Heal、Wobble 或点击 **新建**。旧曲线预设点 **从当前预设生成 Clip**，会保留原曲线内容并生成标准 `.anim`。
2. 点击时间轴选择时间，打开 **自动关键帧**。在窗口预览区拖动移动、旋转、缩放操作柄，或修改左侧的位置、旋转、缩放、透明度、亮度、颜色，直接写入当前时间的关键帧。关闭自动关键帧后属性与操作柄只读。
3. 拖动时间轴的菱形移动关键帧；选中后可精确输入秒数、删除。底部选择轨道并点击曲线字段，使用 Unity 曲线编辑控件调整关键帧与切线。支持 Undo / Redo。点 **保存** 保存 Clip 和预设。
4. **播放 / 暂停、重播、循环、速度** 可即时查看实际 BRG / GPU 效果。文字、字体、字号、换行、飘字寿命和空间模式属于预览设置，不写入动画轨道。

快捷键：W 移动、E 旋转、R 缩放、空格播放/暂停、Delete 删除选中关键帧（输入字段未获得键盘焦点时）。移动中心柄同时改 XY，轴柄只改一个轴；缩放有 X、Y 和双轴柄，Shift 双轴等比。旋转按 Shift 可吸附到 15°。

预设引用 AnimationClip。Clip 的 0～完整时长映射到每条飘字的 0～完整寿命，二者可以不同。**Clip 时长** 会按比例移动全部关键帧和调整切线，保持归一化动画形状。拖动关键帧默认按 Clip 帧率吸附，按 Shift 取消吸附。Clip 保存在预设旁的 `Authoring` 文件夹；不生成编辑 Prefab 或 AnimatorController。

## 固定映射与限制

| 窗口轨道 | AnimationClip 绑定 | GPU 效果 |
| --- | --- | --- |
| 位置 X / Y | 根 Transform `m_LocalPosition.x/y` | 整条文字位移 |
| 旋转 Z（度） | 根 Transform `localEulerAnglesRaw.z` | 平面旋转 |
| 缩放 X / Y | 根 Transform `m_LocalScale.x/y` | 整条文字缩放 |
| 颜色 RGBA | 根 BrgAnimationAuthoring `color.r/g/b/a` | 颜色乘数 |
| 透明度 | 根 BrgAnimationAuthoring `opacity` | Alpha 乘数 |
| 亮度 | 根 BrgAnimationAuthoring `brightness` | RGB 乘数 |

窗口只能写入这 11 条固定轨道，没有层级、添加组件或任意属性的入口。预览数据对象和相机置于独立预览场景，使用 HideAndDontSave，完全隐藏，不会保存到游戏场景；预览文字直接用 BRG 绘制，没有 TMP 编辑物体或每条文字 GameObject。

Position Z、Rotation X/Y 和 Scale Z 仅接受固定中性值（0、0、1）的兼容轨道。四元数旋转、其他组件、资源引用、Animation Events、子物体路径均不接受。外部 Clip 会先验证，非法内容阻止编辑，显示明确原因；只有点击 **修复非法轨道（可撤销）** 才修改外部资源。只读 Clip 不能编辑，需要复制为可编辑 `.anim`。

透明度和颜色 Alpha 输入限制为 0～1，亮度不能为负，数值必须有限。关键帧只能在 Clip 时间范围内；拖动不会覆盖相邻关键帧。制作时自动更新预设中的持久采样数据，构建前再次检查和编译，无效 Clip 阻止构建。Player 不读取编辑器曲线，不需要编辑对象或 Animator。

打开 `TextFeatures.unity` 进入 Play，压力面板 **GPU 动画** 按钮依次切换原有线性动画及四个模板。每次切换清空飘字并重新开始该状态的压力测试。发射量、文字类型、排序、空间模式等原有控制仍然有效。修改正在使用的预设曲线，场景里现存的对应文字也会更新。

## 曲线的含义

横轴是每条飘字的生命周期，0 表示发射，1 表示到期；寿命只改变播放时长，不改变曲线形状。

- X / Y 位移：相对发射锚点的文字布局单位。屏幕空间保持固定大小；世界空间按发射时的布局单位比例转换，随对象变换和相机透视缩放。
- X / Y 缩放：1 为原大小；整条文字一起缩放，包括多行文字和装饰。
- 旋转：角度，围绕整条文字布局中心旋转。
- 透明度：0–1；颜色渐变自身的 Alpha 也参与相乘。
- 颜色：与发射颜色、富文本颜色和字体材质颜色相乘。
- 亮度：RGB 的乘数，不会自动增加描边或 Glow；Glow 仍由字体材质配置。
- 叠加横向漂移：保留发射参数中的随机横向漂移；关闭后完全由 X 曲线控制。

指定动画预设后，Y 位移和透明度由预设接管。预设为空时保留已有线性位移和后半程淡出的行为。曲线按 256 个点采样，GPU 使用线性插值；很窄的尖峰或瞬间跳变可能需要调整曲线宽度。

## 代码中选择动画

`renderer.defaultAnimation` 是新发射文字的默认预设。已有文字继续使用发射时选择的预设；编辑同一预设的曲线则影响所有使用它的现存文字。

```csharp
var pose = new BrgDamageTextRenderer.TextPose(
    position, Quaternion.identity, Vector3.one);
renderer.EmitText(pose, "<b>12345</b>", Color.white,
    animation: criticalPreset, animationAmplitude: 1f);
```

Transform 跟随发射重载也支持这两个参数。`EmitBatch` 的 `TextEmission` 可以逐条指定 `animation` 和 `animationAmplitude`。倍率只改变曲线位移幅度，不改变缩放、颜色、透明度或寿命。单条不指定预设时使用默认预设；批量请求的 `useLegacyAnimation: true` 可以明确使用原有线性动画。

## 执行和性能

AnimationClip 在编辑器中按固定属性编译成持久采样数据。首次使用预设或预设修改时上传共享 GPU 表；运行时不会逐条、逐帧调用 `AnimationCurve.Evaluate`。每条文字发射时记录预设索引和位移倍率，顶点 Shader 根据出生时间和寿命读取三行采样数据，执行位移、缩放、旋转和颜色变化。飘字仍是数据加 BRG 绘制，不创建每条 GameObject，也不使用粒子。

多个动画共用同一张采样纹理，选择不同动画本身不会拆材质或绘制批次。字体资源页和原有排序模式仍可能产生多个绘制命令。全部场景透明排序和世界空间排序需要 CPU 得到动画后的中心位置，此处读取同一份已烘焙数据，不重新求动画曲线。

启用动画会增加顶点 Shader 的三次采样、缩放旋转计算，以及发射时每条 16 字节的动画数据。每个预设有 256×3 个 RGBAFloat 样本；设备不支持浮点线性过滤时使用 RGBAHalf，实际纹理行数按容量扩展。BRG 与普通 Instancing 共用采样动画逻辑。预设在管理器生命周期内缓存，避免反复分配；禁用管理器释放。没有活跃的曲线动画时，Shader 跳过动画采样分支。放大、淡入或延长可见时间也会增加实际覆盖像素，具体成本应在自己的 GPU 和压力条件下测量。

预览使用独立临时数据对象、离屏相机和第 31 层。新 BRG 资源需要经过编辑器帧提交，初次打开可能有短暂准备时间；关闭、脚本重载或切换 Play 模式时释放临时资源。请避免在第 31 层放置需要出现在预览相机范围内的普通场景模型。
